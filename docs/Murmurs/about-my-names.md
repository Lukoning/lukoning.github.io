# 关于我的「名字」

---
### 1. <em><lkn c homehero>Lukoning</lkn></em>

是我想的…可以说是第一个确定的、专属于我自己的（英文？）名字。

起名的时候考虑了英语发音问题（正字法），也考虑了重名的问题。它与我的本名有部分谐音，并融合了一个我熟悉的地名。通常我把它当作很正式的英文网名使用。

### 2. <em><lkn c green>Ao</lkn><lkn c yellow>hina</lkn></em> (<lkn c green>あお</lkn><lkn c yellow>ひな</lkn>)

<ruby>雪村<lkn c green>あお</lkn>い<rp>(</rp><rt>Yukimura <lkn c green><c>Ao</c></lkn>i</rt><rp>)</rp></ruby> - 雪村葵

根据日语惯例，将两人合称为<ruby><lkn c green>あお</lkn><lkn c yellow>ひな</lkn><rp>(</rp><rt><lkn c green><c>Ao</c></lkn><lkn c yellow><c>hina</c></lkn></rt><rp>)</rp></ruby>，以此命名。

第一次看向山进发以来，社交应用的头像、主页封面许多都有她们。不过也有例外，这些例外大多来自「原神」，就算不是至少都是二次元。

### 4. 白河豚🌻

一开始在QQ上用，当时并没有「白河豚」这么“直白”，而是只有一个「🌻」。也就是：

<p><lkn c green>雪村あおい</lkn>/<lkn c yellow>倉上ひなた</lkn> -> <lkn c green>雪村葵</lkn>/<lkn c yellow>仓上日向</lkn> -> <lkn c green>葵</lkn><lkn c yellow>日向</lkn> ->「<lkn c yellow>向日</lkn><lkn c green>葵</lkn>」->「🌻」</p>

但后来觉得只有一个表情符号太过隐晦了，于是加上了「白河豚」。

「白河豚」即「百合豚」。

### 5. 星喵

只是为了创作而起的笔名，是从脑海里忽然蹦出来的。后来我想，这真是一个好名字：

「星」这个意象于我来说可以象征着很多东西，用来作为概括是合情合理的；

「喵」就简单了，谁不喜欢一位柔情猫娘/猫郎呢？（再不济就当装可爱了）

### 6. 言涵莲

女名，玩恋与深空时给自己起的名字。

这可是认真起的喵！甚至考虑了生辰八字……

[这篇小说](/Murmurs/Heartspace/hanlian-jinsong-leishui-fiction)借用了它，作为小说主角的名字。

### 7. 言松涵

男名，为了给「言涵莲」对应而取的名字，取名的直接动力是在《原神·千星奇域》里给男性奇偶取名字。

嗯…是自己的名字，不过「设定」上是言涵莲的弟弟。

另外“松”字有深意。我不说。

### 8. 异世界的璃月人

以前的原神昵称。璃月的原型是中国，璃月是“异世界的中国”，那么“异世界的璃月”就是中国。

整个名字的意思是“中国人”。

《原神》，启动！
