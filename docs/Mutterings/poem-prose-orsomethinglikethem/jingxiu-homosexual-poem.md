# 镜袖

#### 第二版 2026-03-29

断袖情深无人问，磨镜帕交不为然。

情至磨镜舆不顺，爱达断袖贬自来。

古有民间金兰会，书载曾盛契弟兄。

如今镜袖归另类，破镜残袖仍相拥。

天公未禁何不可？此道从来自有之。

人情人欲生非异，然曰殊类益疏隔。

# 镜袖

#### 第一版 2026-03-17

磨镜之恋，有的人看轻。

断袖之爱，有的人嫌弃。

自古有载这王那皇好同性，

自古民间龙阳金兰不断靡。

今言男女本性必有异，

更有镜袖划归对立系。

纵然是长颈麒麟，也更与雄交不止雌。

就算是家养虎皮，也曾试同性反挨击。

此为自然之道，有何不可？

镜袖生非异也，然曰异也。
