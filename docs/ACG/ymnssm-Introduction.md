# 关于ヤマノススメ（向山进发）

参见：[向山进发 - 萌娘百科](https://mzh.moegirl.org.cn/index.php?title=%E5%90%91%E5%B1%B1%E8%BF%9B%E5%8F%91&oldid=8069466)

原著漫画，作者しろ，发行于EarthStar。改编有番剧，一共4季+1部OVA。（无感情）

「埼玉县 饭能市」是向山进发故事发生的主要场景。葵和日向上的高中，其原型是饭能市圣望学园（[聖望学園公式サイト](https://www.seibou.ac.jp/)）。

向山进发讲述了葵不小心碰见自己的幼驯染日向，随后被幼驯染拉着再次向山进发的故事。
